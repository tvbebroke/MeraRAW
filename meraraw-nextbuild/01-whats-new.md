# 01 — What's New in Lightroom CC

**Applies to:** Desktop v2.0, Mobile v4.0, Web — **[BUILD: October 2018]**

## Purpose
Release-context chapter. Establishes the Oct 2018 baseline feature set that the rest of
the document assumes. Low direct implementation value; use as a feature checklist.

## Headline features introduced at the v2.0 baseline
- **Auto-update** of the app; two versions cannot run simultaneously; preferences migrate
  forward automatically. `[BUILD: v2.0]`
- **People View** — ML face detection groups photos by person. (See file 15.)
- **Search improvements** — type-ahead suggestions; metadata-scoped filters
  (e.g. `camera:`, location). (See file 07.)
- **Brush + Linear/Radial Gradient local color** — local adjustments can now apply a
  **color** (hue) in addition to tonal controls. `[BUILD: 2019 / v2.x]`
- **Share any selection as a web gallery** (not just whole albums). (See file 08.)

## IMPL
- Treat this file as the canonical "feature flags present at baseline" list. Cross-check
  each flag against files 05–15 for the actual spec.
- The "single running instance" constraint is an app-lifecycle requirement, not a feature.
